PaaS Deployment (GitHub Pages)

ขั้นตอนการ Deploy เว็บไซต์ขึ้น GitHub Pages

สรุปลำดับขั้นตอนตามข้อกำหนดเพื่อนำส่งงาน (5 คะแนน) พร้อมเครื่องมือสร้างและทดสอบ URL

1

สร้าง Repository บน GitHub

เข้าสู่เว็บไซต์ github.com ล็อกอินบัญชีของคุณ จากนั้นกด New Repository ตั้งชื่อ เช่น minimart และเลือกเป็น Public

2

อัปโหลดไฟล์เว็บไซต์

อัปโหลดไฟล์โปรเจกต์ทั้งหมด (index.html, style.css, app.js และโฟลเดอร์ images/) เข้าสู่ branch main

3

เปิดใช้งาน GitHub Pages

ไปที่แท็บ Settings > เมนูซ้ายมือเลือก Pages > ที่หัวข้อ Build and deployment เลือก Source เป็น Deploy from a branch เลือก Branch main / (root) แล้วกด Save

4

รับ URL และแนบส่งงาน

รอระบบ Build ประมาณ 1-2 นาที จะได้ URL ในรูปแบบ https://<username>.github.io/<repository>/ สามารถคัดลอก URL ไปแนบส่งงานได้ทันที

🚀 เครื่องมือสร้าง & แนบ URL GitHub Pages ของคุณ:

URL สำหรับส่งงาน: https://your-username.github.io/minimart/
