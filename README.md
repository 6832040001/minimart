## 🚀 ลำดับขั้นตอนการ Deploy บน GitHub Pages (PaaS)
1. สร้าง New Repository บน [GitHub](https://github.com/) ตั้งชื่อ `minimart` (เลือก Public)
2. อัปโหลดไฟล์ทั้งหมด (`index.html`, `style.css`, `app.js`, โฟลเดอร์ `images/`)
3. เข้าเมนู **Settings** > **Pages**
4. ที่หัวข้อ **Build and deployment** ให้เลือก Branch เป็น `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
5. รอ 1-2 นาที จะได้ URL: `https://<username>.github.io/minimart/`
